# Hilal Al-Sharq Unified Tools Suite

This package merges the tools from folders `1`, `2`, and `3` into one deployable website folder.

## Entry point
Open `index.html`.

## Included pages
- `ledger_analyzer.html` — Customer / ledger analyzer from folder 1.
- `account_statement.html` — Account statement generator from folder 1.
- `operations_tools.html` — Cake, returns, and gifts calculators from folder 2.
- `inventory_manager.html` — Inventory monitoring dashboard from folder 3.

## Styling
The landing page and shared visual direction use the purple/yellow Hilal Al-Sharq style from folder 1. The merged calculator and inventory pages were patched to use the same brand palette, shared icon, and homepage navigation.

## Notes
The original tools still use their browser-side JavaScript logic. Some pages load external browser libraries from CDNs, the same as the original source files.
